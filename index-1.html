04 / PROJECT INFORMATION

ABOUT BITBINDER DEVELOPER

COMMUNITY PROJECT

BitBinder — From Indonesian Community

BitBinder adalah proyek edukasi teknologi yang dirancang untuk membantu developer pemula mengenal berbagai jalur karier IT, belajar mandiri, mencoba kode, dan membangun portofolio.

Platform ini menyatukan roadmap pembelajaran, direktori tools, tautan karier, JavaScript Playground, dan AI Research Tutor dalam satu antarmuka.

Developer: BitBinder Community
Fokus: IT Education, Developer Tools, AI-assisted Learning
Website: bitbinder.netlify.app

AI ENGINE

BitBinder AI Research Tutor

Fitur AI terhubung ke backend serverless Netlify Functions dan menggunakan OpenRouter sebagai gateway model AI. Model yang dipakai ditentukan oleh konfigurasi backend, bukan dikunci oleh tampilan website.

API key disimpan sebagai environment variable di Netlify dan tidak ditanam di browser. Chat dikirim ke endpoint backend BitBinder untuk diproses.

Browser UI ↓ HTTPS POST Netlify Function ↓ API request OpenRouter AI Gateway ↓ AI response → BitBinder
